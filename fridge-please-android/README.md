# 🥬 냉장고를 부탁해 — 안드로이드 네이티브 앱 자동 APK 빌드 패키지 (Flutter)

내 PC에 안드로이드 스튜디오나 개발 도구를 설치하지 않고, **GitHub에 폴더를 올리기만 하면 5분 만에 실제 안드로이드 `.apk` 설치 파일이 자동으로 만들어지는** 네이티브 앱 프로젝트입니다.

---

## 🚀 내 PC 개발 도구 없이 `.apk` 파일 뽑는 방법 (4단계)

### 1단계: GitHub 무료 저장소 만들기
1. [GitHub](https://github.com)에 로그인합니다. (무료 계정)
2. 우측 상단 **`+` → `New repository`**를 클릭합니다.
3. Repository name에 `fridge-please-app`을 입력하고(Public 또는 Private 모두 가능), **`Create repository`**를 누릅니다.

### 2단계: 압축 푼 파일 업로드하기
1. 다운로드한 `fridge-please-android-github.zip`의 압축을 풉니다.
2. 생성된 GitHub 저장소 화면에서 **`uploading an existing file`** 링크를 클릭합니다.
3. 압축을 푼 `fridge-please-android` 폴더 **안의 모든 파일과 폴더**(`.github`, `assets`, `lib`, `scripts`, `pubspec.yaml`, `README.md`)를 그대로 드래그 앤 드롭한 뒤, 하단의 **`Commit changes`** 버튼을 누릅니다.
   > ⚠️ **중요:** 반드시 `.github` 숨김 폴더가 함께 올라가야 자동 빌드가 실행됩니다! (Windows/Mac에서 숨김 파일 보기 설정 후 전체 선택해서 올려주세요.)

### 3단계: 자동 `.apk` 빌드 확인 (약 3~5분 소요)
1. 업로드 직후 상단 **`Actions`** 탭을 클릭하면 **`Build Android APK (냉장고를 부탁해)`** 작업이 자동으로 돌아가는 것을 볼 수 있습니다.
2. 초록색 체크 표시(✅)가 뜨면 `.apk` 생성이 완료된 것입니다.

### 4단계: 스마트폰에 `.apk` 바로 다운로드 및 설치
1. 저장소 메인 화면 우측의 **`Releases`** 메뉴를 클릭합니다.
2. 최신 릴리스의 **`fridge-please-android.apk`** 파일을 스마트폰에서 직접 터치해 다운로드합니다.
3. 다운로드된 `.apk` 파일을 실행해 설치합니다. *(설치 시 '출처를 알 수 없는 앱' 허용 팝업이 뜨면 허용해 주세요.)*

## ✨ 탑재된 네이티브 앱 핵심 기능
* **진짜 백그라운드 D-3 푸시 알람:** 앱을 완전히 꺼두거나 스마트폰을 재부팅해도 만료 3일 전(냉동은 7일 전) 지정 시각에 안드로이드 자체 알람이 울립니다. (*알림·설정 탭에서 10초 뒤 백그라운드 알람 테스트 가능*)
* **실제 카메라 AI 판독 (Gemini 2.5 Flash):** 설정 탭에 무료 Gemini API 키(`aistudio.google.com`)를 입력하면 채소 신선도 판별, 기성품 소비기한 OCR 추출, 마트 영수증 일괄 등록(비식자재 자동 제외)이 실시간으로 동작합니다.
* **냉장 ↔ 냉동 원터치 전환:** 보관 구역을 바꾸면 권장 섭취 기한, 냉동·해동 팁, 네이티브 알람 예약(D-3 ↔ D-7)이 한 번에 자동 재계산됩니다.
* **임박 식자재 AI 저녁 레시피 추천:** D-3 이내 임박 식자재를 우선 선택해 저녁 메뉴를 추천하고, 요리 완료 시 자동 소비 처리 및 식비 절약 리포트에 기록됩니다.
